Why is frontend-only RBAC insecure?Answer: Frontend code runs on the user's browser and can be modified or bypassed via DevTools, network interception, or direct API calls (e.g., Postman). Authorization must be enforced on the backend via JWT checks and database query scopes.  How are duplicate webhook events prevented?Answer: By creating a unique index on provider_message_id in MongoDB. Before processing, check if the ID exists; if so, reject or ignore the request (Idempotency).What happens if the AI service is unavailable?Answer: Catch timeout/connection exceptions, log the failure, fallback to saving the raw customer message, and automatically raise a human escalation so the lead isn't lost.  Why is AI not allowed to automatically send replies?Answer: To prevent prompt injection, hallucinated promises, compliance issues, or bad customer experience. The AI generates a draft, and a human agent reviews and approves it.How would the application handle 100,000 leads?Answer: Database indexing on queried fields (status, assigned_to, created_at), API-level pagination (page/page_size), read-replicas, and moving heavy background workloads to a message queue.
